How to use

Series

  • Expand a service in the left tree to decode it, then click a field to add it to the active plot (outlined), or drag it onto any plot.
  • The filter matches all words, e.g. carstate steer. Use Load all services to search every field.
  • Paths follow openpilot's jotpluggler: /carState/vEgo, /modelV2/laneLines/0/y/0. Scalar lists longer than 64 are not split into series. Each service also gets /valid, /logMonoTime and /t.
  • CAN: expand can / sendcan for raw bytes per bus and address; load a DBC to get signals as /can/<bus>/<Message>/<Signal>.

Plots

  • Drag to pan · wheel to zoom time · Shift+drag to zoom to a time range · Ctrl+wheel to zoom the value axis · double-click to show the whole data range.
  • The cursor follows the mouse and is shared by all plots, the tree values, the logs and the inspector.
  • Legend: click a name to hide it, × to remove it. Pane buttons split the pane down or right, or close it.
  • Keys: ← → pan, + − zoom, Home whole data range, Esc release the value-axis zoom of the active plot.

Time

Seconds since the earliest logMonoTime of the loaded files (as in jotpluggler). Segments repeat a few messages stamped at the route start, so a later segment starts well after 0; the initial view and double-click show the range where the data is. Values at the cursor are the latest sample at or before it (jotpluggler interpolates between samples).

Layouts

Built-in layouts are openpilot's jotpluggler layouts; import and export use the same JSON format. Custom Python series are evaluated with Python's meaning when they are a one-line return expression (see the README for the supported subset); anything else is shown as unsupported, never approximated. Camera and map panes are not supported.
